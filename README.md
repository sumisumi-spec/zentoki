# ZENTOKI｜断食・瞑想タイマー

**自分を整える時間を、日常に。** ZENTOKI（ゼントキ）は、断食タイマーと瞑想タイマーをひとつにした Web アプリです。
ZEN〈禅〉× TOKI〈時〉。食事の間に余白をつくり、心にも余白をつくる。

English: **Make time for yourself.** Fasting and meditation, in one app.
依存ライブラリなし、単一の `index.html` で動作します。

## 画面構成

- **ホーム**: 断食タイマー（リング・残り時間・プラン・体の変化）と瞑想タイマー（時間・呼吸法・開始）
- **サウンド**: 雨音 / 波音 / 森 / 焚き火 / 小川 / ドローン / バイノーラル / メロディ、音量、自動停止、チャイム
- **記録**: 断食の統計とカレンダー、瞑想の記録、体重ログ

初回起動時はタイトル画面（JP / EN切り替え）から「はじめる」で入ります。

## 機能

- プリセット: 12:12 / 14:10 / 16:8 / 18:6 / 20:4 / OMAD / 36h / カスタム
- 進捗リング・経過時間・残り時間・目標時刻の表示
- 開始時刻の後から修正（食事を終えた時刻を入れ忘れた時用）
- 経過時間に応じた「体の変化」ステージ表示
- 断食終了後の食事ウィンドウのカウントダウン
- 履歴・統計（回数 / 連続日数 / 平均 / 最長）と直近7日のグラフ
- 瞑想タイマー（3〜30分。マインドフルネス: ガイドなし / 5-5 / ボックス、リラックス: 4-7-8 / 4-8 / 5-10 / 6-12 / 7-14。おりんの音、波紋が呼吸に同期、画面スリープ防止、セッション記録とカレンダー表示）
- 体重ログ（目標・開始体重・進捗バー・推移グラフ・BMI）
- Apple ヘルスケアの書き出しファイル（export.xml）から体重を取り込み
- 目標達成・ステージ到達の通知（ブラウザ通知）
- サウンド: Web Audioでその場で生成する 水音 / ドローン / バイノーラルビート（2・6・10・16Hz、水音の重ね合わせ可）/ 生成メロディ（Aメジャーの環境音楽）、節目のチャイム。音源ファイル不要。背景の波紋は音の出来事（音符・水滴・うねり）に同期して発生
- バックアップ（ファイル書き出し / テキストコピー / 読み込み）、背景の波紋アニメーション（設定でオフ可）
- 初回起動のオンボーディング、プライバシーと利用について（アプリ内 + privacy.html、日英）
- PWA 対応（ホーム画面に追加・オフライン動作）

## 使い方

ローカルで試す:

```sh
# このリポジトリ直下で
python3 -m http.server 8080
# http://localhost:8080 を開く
```

`index.html` を直接ダブルクリックしても動きます（その場合 Service Worker は無効）。

公開版: https://sumisumi-spec.github.io/zentoki/

iOS アプリ版のビルド手順は [docs/IOS_RELEASE.md](docs/IOS_RELEASE.md) を参照。
スマホでは「ホーム画面に追加」でアプリのように使えます。

データはすべてブラウザの localStorage に保存され、外部には送信されません。
